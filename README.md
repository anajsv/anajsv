#### IntegraSol
**Numerical integration, made visible.**

Um protótipo acadêmico desenvolvido em dupla para Cálculo III na UNIR. O projeto explora a aproximação numérica de integrais triplas por somas de Riemann em uma esfera com densidade constante, combinando cálculo e visualização 3D.

**Minha contribuição**
- Configuração do ambiente Python 3.12.
- Implementação de partes da lógica de cálculo numérico.
- Colaboração nas funcionalidades de visualização 3D.
