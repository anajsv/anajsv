### IntegraSol

**Interactive prototype for numerical approximation of triple integrals**

Academic project developed in a pair for Calculus III at UNIR. It demonstrates Riemann-sum approximation inside a sphere with constant density, connecting numerical calculations with 3D visualization.

**My contribution**
- Configured the Python 3.12 environment.
- Implemented parts of the numerical calculation logic.
- Collaborated on 3D visualization features.
